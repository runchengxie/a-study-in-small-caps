# A Study in Small Caps

[简体中文](README.zh-CN.md) · [Open the website](https://runchengxie.github.io/a-study-in-small-caps/)

Why do small stocks sometimes rise sharply, and why can they be so hard to sell when prices fall? This project investigates small-cap investing across markets, starting with the evidence we can check.

You can read the investigations, explore interactive charts, and compare findings with published papers. The site also keeps earlier research and records when a conclusion changes. Start with the overview, or open the investigation into the 2024 small-cap drawdown.

The research is ongoing. Each chapter explains its sample and limitations. Historical returns shown in a chart do not guarantee that an investor could have traded at those prices.

## Run it on your computer

Install Node.js 24 or newer, then run these commands in the repository folder:

```sh
npm ci
npm run dev
```

Open the local address printed in the terminal. Press `Ctrl+C` to stop the server. You do not need a Databricks account or vendor credentials to run the website.

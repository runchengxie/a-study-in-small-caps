# 滚动研究导览

[English](scroll-guide.md)

首页沿用收益、回撤和成本的顺序。每段让 SVG 图表停留在屏幕上，短段文字随滚动推进。向上滚动可以回看。读者可以切成自由查看，直接操作图表也会停止自动切换，研究目录仍可直接进入。

比较过入场动画、全屏画布和分段固定图表。选用分段固定图表，方便保留来源和键盘操作，也不会延长封面 WebGL 的运行时间。没有引入参考网站的代码或图像。

收益曲线依次展开至2015年、2020年和完整样本，固定对数坐标。回撤依次展示完整样本、2024年和完整样本，各窗口都保留完整序列此前的高点。成本使用明确标示的假设价差与替换比例，不从历史净值中直接扣减。每张图旁保留影响解释的限制。

基础 HTML 保持可读。减少动态效果时关闭自动跟随和长滚动间距。小屏幕或放大页面后，图表若无法完整容纳，就采用普通排版。滚动、调整窗口和操作控件时才更新，没有持续动画循环。浏览器检查覆盖前后滚动、手动接管、中英文切换和静态回退。

2026年11月27日参考了 [Highline](https://highline.huffingtonpost.com/articles/en/poor-millennials/) 的连续图文阅读方式，以及 [Hunterbrook](https://hntrbrk.com/investigations/amd-china) 将图与来源放在一起的呈现方式。两篇报道未被用作本站投资研究结论的来源。直接浏览器预览不可用，本轮阅读了文章内容与 Highline 的公开交互实现。

# Visual research references

The linked research instrument draws on the focus-and-context interaction described in [Observable's linked brushing guide](https://old.observablehq.com/blog/linked-brushing) and [D3's focus/context example](https://observablehq.com/@d3/focus-context). The [European data portal's calendar heatmap guide](https://data.europa.eu/apps/data-visualisation-guide/calendar-heatmap) informs compact time-based comparisons. Implementation code is original.

The user also suggested r/dataisbeautiful. Search results did not provide a sufficiently accessible original example to attribute a specific implementation to that community. The selected references above document the interactions used here.

Charts derive from the already published NAV snapshot. Monthly returns require prior month-end levels; incomplete boundaries are marked. Drawdown keeps the full-source running peak when selecting a shorter view. Overlapping holding windows remain dependent observations. The homepage illustration is separate from these measured historical figures.

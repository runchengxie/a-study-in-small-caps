# Particle wave source

The homepage directly adopts Enrichr's published **Particle wave hero** source from [the author’s machine-readable export](https://enrichr.dev/elements/particle-wave-hero.json), associated with [the requested CodePen](https://codepen.io/Enrichr-Dev/pen/ogZJMJp). It replaces the earlier custom terrain imitation. This is the author's vanilla WebGL export, not a claim that it is a byte-identical copy of the CodePen runtime.

The unchanged export fields are retained under `public/third-party-notices/enrichr/`, with SHA-256 digests and the exact preview licence. The source is used under that stated licence; no MIT licence is asserted for this export. The visible attribution in the site footer links to Enrichr without adopting its logo or suggesting a partnership.

`src/vendor/enrichr/particle-wave.js` preserves the 32,000-particle distribution, camera, pointer ray, scroll easing and text transforms. The vertex shader adds a slow rightward phase shift to the existing wave terms. Dark mode retains additive blending; light mode uses alpha blending with a warm-paper background and muted copper particles. Its explicit JavaScript type-check exception keeps the original author source reviewable; `particle-wave.d.ts` and `src/lib/terrain.ts` provide the strictly typed integration boundary. The author CSS is unchanged.

Local changes to the JavaScript are limited to the ES module export, translated corner labels, pause/live reduced-motion controls, stopping animation scheduling while hidden or offscreen, context restoration/cleanup, the lateral wave phase, theme-specific blending and a sparse hover-column treatment. The publication adapter supplies its bilingual title and caption. The publication retains translated title markup so the Chinese micro glyph can use a smaller size on the same baseline, while the English title uses lowercase text. The markup uses an h1, decorative canvas, a research anchor and pause control. Shell CSS fits the existing viewport below navigation, removes the standalone card radius and keeps the research link accessible on small screens. The hero uses a coffee background and copper-gold particles in dark mode and follows the publication's light, dark or system preference without recreating the canvas. The typed adapter supplies the light palette; text and fallback colours are overridden in the publication stylesheet. Original source snapshots remain unchanged.

Validation: `npm test`, `npm run check`, `npm run build`, `npm run test:e2e`. Browser tests exercise rendered output, scroll text transforms, pointer output, pause, live motion preferences, context loss/restoration, translation and viewport fit.

Hover columns reuse the point-sprite shader and its existing single draw call. Within a small screen-space radius, 14% of particles are eligible to stretch into slim copper bars. The height increment is capped at 18 CSS pixels, with eased appearance and retraction. Touch input does not activate the effect; pause and reduced-motion controls apply to it. These bars are decorative and encode no market returns. The source snapshots and attribution remain unchanged.
